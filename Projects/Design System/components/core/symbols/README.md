# Interaction symbols

This is the scoped, shared symbol library Mark requested on 27 September 2026. It contains two marks only; it does not settle or reopen the broader icons-vs-pictograms research.

- **Rotation orbit:** a dashed ring with the inverse of the card's polarity mark — two outward-facing triangles — repeated at both horizontal sides (four triangles total). Each triangle uses the flip mark's exact 11 × 11 geometry and 2-unit gap. `symbols.js` places both pairs for the Flower's measured radius, with each outer tip exactly on the orbit. The marks stay level while the flower turns, with no arrow shafts.
- **Polarity pair:** `polarity-pair.svg`, two filled triangles pointing towards each other. The card flip control uses it as a monochrome mask, inheriting the control's current colour.

Both use the system's monochrome mark colours, simple geometry and the existing type/space scale. Brand STYLE's Symbols section is the visual register. Add no further marks here without a specific use and ruling.
