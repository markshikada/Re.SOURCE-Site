The design workbench after Claude Design

What replaces Claude Design: one surface you own, links that never move, and sessions that open nothing on your screen.

Bottom line

The tab was never the container. A preview tab is a handle on a session’s own server. The session ends, the handle drops, and the page it showed is gone. No tab habit fixes that, because the tab was never holding the work.

The canvas is half built already. The public site carries the working design masters at fixed links that never change, on any device. What is missing is currency: lanes publish at wrap, so the link shows the last finished state rather than the work.

One surface you own. A standing live view on the Mac, opened once and kept, always showing the current masters with no session attached. Sessions stop opening windows in your interface entirely; their own checks happen as captures they read themselves.

The shape of it

Fixed links, forever

Each master keeps one address for its whole life. One bookmark opens the set on the phone and on the Mac. The address never changes, so anything the browser remembers stays with you.

Already true on the site · tested today

Checkpoint publishing

While a lane works, it publishes the working folder at each shape change, about a minute a time. The fixed link then shows the current work across sessions, not the last wrap-up.

One command · stages the working folder, even mid-lane

The standing live view

A small always-on server on the Mac serves the vault folder with live reload. You open it once and keep it; it always shows the current masters, whatever session last touched them. It wraps the folder from outside, so no master file changes for it.

What stops today, whatever you rule

Sessions stop opening browser windows. This is your correction of 28 September, not an option on the menu. A session checks its own work with captures it reads itself and throws away, and nothing opens on your screen as part of routine work.

What reaches you stays what reaches you. A chat reply and a visual page at the moment they matter. Only now the visual page is something you open when you choose, at a link that never moves.

The editing tools, compared

Your test was never price. Claude and Kimi design apps were proprietary and OpenCode could never work in them. So a candidate has to pass three things at once: free, better hand tools than the makeshift panels in the masters, and OpenCode working in the same file as you.

Penpot is the one that passes all three. Free forever, unlimited design files. A real drawing canvas with components, design tokens, flex and grid layout, prototyping. Its official MCP server connects straight to OpenCode, and Penpot’s own guide is written for OpenCode. Agents create and edit in the same file you draw in. That is exactly the property whose absence killed the other two tools.

Penpot pricing, MCP server, OpenCode guide · all checked today

Inkscape is the deepest free vector editor there is: pen, nodes, boolean ops, all of it. It works with OpenCode in the plainest way possible – it edits SVG files in the vault and agents edit the same files. No shared canvas though: you and the agents take turns on a file rather than working in it together.

Inkscape · free, open source · desktop app · checked today

The masters’ own tools, which you have now: Tools, Sets, Effects. They beat everything above at one thing, and it is the important one – they edit the live master itself. But they are value panels, not drawing tools. Nothing there draws a new shape by hand.

The masters today · free · already built

What the Penpot trial costs you. A drawing lives in Penpot’s own storage, so it is a second place to keep unless a round trip is held open. The MCP is what holds it: work moves both ways instead of being re-authored. Hosted means designs sit on their servers; self-hosted keeps everything on the Mac and needs Docker.

The honest trade · the trial is what settles it

Claude Design’s lesson, and why this one is different. Its canvas format proved not portable: the subscription ended and only finished exports came out with it. Penpot is the opposite shape – open formats throughout (SVG, CSS, HTML, JSON), self-hostable, no subscription that can end.

COMMAND record, 15 August 2026 · Penpot docs

How a trial would look. One real piece of work, not a toy. I connect OpenCode to a free Penpot file, we take something small from the queue – a card face, an icon set – and you judge the hand tools yourself against your panels. Nothing in the vault changes until you say so.

Your call, three decisions

All three are ruled, 28 September: A, A, A. The options below stand as the record of the choice, each ruled one marked.

Decision 1 of 3

What carries the workbench

The shape that replaces Claude Design for carrying design work on across sessions.

AStanding live view and fixed linksRuled

The standing live view on the Mac is the workbench: one surface, opened once and kept, always showing the current masters. The fixed links carry the same work to the phone and outside the house, kept current at checkpoints. Sessions open no windows at all.

BStanding canvas only

Same fixed links and checkpoint publishing, nothing new on the Mac. Watching costs a refresh after each checkpoint.

CStanding live view only

Live at the Mac and on the phone at home, and nothing of the working state goes near the public site. No continuity outside the house.

DA hosted design app

A real canvas tool of the Penpot kind. The masters would need re-authoring, it makes a second source of truth, and it brings back a subscription. See “The editing tools, compared” above for what that means.

Decision 2 of 3

What the public link may show

The site is readable by anyone holding the link today, by your own ruling of 20 September.

AThe working state tooRuled

The fixed link shows the current work, rough edges and all. Simplest, and nothing is exposed that the link-holder cannot already reach.

BTwo areas, working and finished

One link set carries the working state and another carries the finished pages, so rough work never sits beside finished work.

CFinished states only

Working state never publishes. You watch at the Mac, and the public link keeps only what has been wrapped up.

Decision 3 of 3

What needs your hands

Only the pieces a session cannot install for you.

AOne command on the MacRuled

The standing live view comes as a small script and a login item. You run one command and it starts with the Mac.

BSkip the Mac piece

Nothing to install. The fixed links carry everything until you ask for the desk view.

CAlso Tailscale

The phone and the Mac join one private network, so the standing live view works outside the house too. Two app installs, both yours.

How to rule

Tap your ruling in the chat’s own question box. Each option there names in a line what tapping it does, and the recommended one comes first. Tapping is the ruling, and the session then builds it without asking again.
