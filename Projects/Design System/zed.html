Keys Agents Estate

The editor

Everything Zed does for you, on one card.

Six keys run this workspace. Each one opens a different agent, and each agent has one job. If a key does not fire, the palette does: cmd-shift-p, then type the action name.

The six keys

alt-1 to alt-4 are the four agents

alt-1

Intel

Judgement and research. Reads the vault first, then brings you options with a recommendation. Never guesses where a person must rule.

alt-2

Ops

Mechanical execution. Audits, sweeps, publishing, quota, repo hygiene. Routes judgement calls back to you rather than making them.

alt-3

Design

Craft and visual work. Pages, specimens, motion, responsive passes. Researches first, drafts only once told to.

alt-4

Design review

The critic's eye. Checks a named surface against the masters and reports findings in severity order. Cannot edit.

alt-o

Carry on

Reopens whatever you were doing in this folder, in the same session. alt-shift-o runs that last command again.

cmd-shift-p

The palette, which finds everything

Every action Zed has, searchable by name. Start here whenever a key does not do what this card says.

How work moves

One sentence each, and who to ask

Intel decides

Anything asking what should this be, what does the evidence say, or write the brief.

Give it the question, not the answer you want.

Ops does

Anything asking sweep, audit, publish, check the quota, fix the repo.

Tight briefs. One cohesive ask beats five small ones.

Design makes

Anything asking build this page, try that direction, make it feel right.

It looks at its own work at 12, 6 and 3 columns before showing you.

Both seats are free. LongCat leads, SpaceBunny is the fallback, and no paid model is reachable from any of these keys — which is why nothing here can end in an insufficient-funds error.
