Approve MacCrab's system extension

MacCrab uses Apple's Endpoint Security framework to monitor system events. macOS requires your explicit approval before it can run.

1 What to do

1
Open System Settings Click the blue button above, or go to System Settings → General → Login Items & Extensions
2
Find Endpoint Security Extensions Scroll down to the "Endpoint Security Extensions" section (near the bottom)
3
Toggle MacCrab ON Click the toggle switch next to "MacCrab Endpoint Security Extension" so it turns green
4
Enter your password if prompted macOS will ask for your admin password to confirm the change

Grant Full Disk Access

All three tools need Full Disk Access to monitor files and processes across your entire Mac. Without this, they are blind.

1 What to do

1
Open System Settings Click the blue button above, or go to System Settings → Privacy & Security → Full Disk Access
2
Click the + button Click the "+" button at the bottom of the list to add a new app
3
Add MacCrab Navigate to /Applications and select MacCrab.app
/Applications/MacCrab.app
4
Add BlockBlock Navigate to /Library/Objective-See/BlockBlock and select BlockBlock.app
/Library/Objective-See/BlockBlock/BlockBlock.app
5
Add OverSight Navigate to /Applications and select OverSight.app

Enable MacCrab protection

MacCrab's daemon needs to be started. This activates the detection engine and begins monitoring.

A web page cannot do this. Nothing here can launch a Mac application — the old control tried open -a MacCrab, which is a Terminal command, not something a browser can execute. Open MacCrab from your Applications folder instead.

1 What to do

1
Open MacCrab Open MacCrab from your Applications folder (/Applications/MacCrab.app) — a web page cannot launch it for you
2
Click "Enable Protection" The main window will show a button to enable the detection engine
3
Wait for the daemon to start The status should change from "Not running" to "Running" within a few seconds
