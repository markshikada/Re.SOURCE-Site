What a worktree is

What it is, what was wrong, and what changes overnight. Plain words, no jargon.

The one idea

A worktree is a second desk in the same room. Same history, same piles of paper, but a separate desk with its own branch of work on it. You can have ten desks open at once, each with different work, and no two sessions ever fight over the same files.

A symlink worktree is a worktree that does not duplicate the heavy, temporary stuff: the folders Git never copies because they are not part of the project. Build output, installed packages, caches, secret files. Instead it points back at the main copy. One heavy folder, shared by pointer, built once and never twice.

What we already do

  • Every piece of work gets its own desk: a worktree, a branch, a pull request.
  • Git refuses to put one branch on two desks, so two sessions cannot collide.
  • Work merges into the main copy through a pull request, one merge method only.
  • Estate rules are written down and followed by every lane.

What changes overnight

1Desks will close themselves.

When a pull request merges, the desk and its branch clear automatically. Nothing accumulates.

2One register, always current.

Any session can read which desks are live, what each is for, and how old it is.

3Heavy folders shared, not copied.

A lane points at the shared build folder rather than making its own, so nothing builds twice.

4The two main copies rescued, not touched.

At-risk work preserved on a branch and put in front of Mark as a pull request to review in the morning.

What is still open

  • Rescue pull request from the two main copies needs Mark's review. It is another session's work, so it is his call.
  • One repository parked on a side branch needs to go back on its main branch.
  • One orphaned detached worktree with no branch is being reported, not removed.

The video that prompted this

Mark sent a short comic video: a parody of an engineer who replaces himself with sixteen agents in separate worktrees sharing one symlinked build folder. It got the shape right, separate desks with a shared heavy folder, and it got silly about the rest. Estate took the good idea from it: one desk per piece of work, heavy folders shared by pointer.
