Lane pipeline

Launching sessions, listening for completion, analysing, correcting, merging once.

Five stages

Left to right on a desktop, top to bottom on a phone. One sentence of what happens, one rule that governs it.

01

Launch

A queued task becomes a branch the moment its brief reaches an engine.

Rule

One repo per session on main, and the dispatcher's note leads the brief.

02

Listen

The branch state on GitHub is the signal, not the session's own report.

Rule

Watch commits and pull requests. A claim of done is not a signal.

03

Analyse

The dispatcher reads the diff and runs the checks the brief's Done-when names.

Rule

Look at it at 12, 6 and 3 columns, and check the Don't-touch lines as hard.

04

Correct

Findings go back to the same lane while its branch is still alive.

Rule

Corrections land in files, not only in chat.

05

Merge once

One merge, issued after acceptance, is the lane's final act.

Rule

Push as work lands, open the PR early, merge late and once.

Signals

Seven states the listener reads off GitHub, and the dispatcher's answer to each.

Signals, what each means on GitHub, and what the dispatcher does about it
SignalOn GitHubDispatcher
LAUNCHED A new arena/* or work/* branch, or a new PR. Row recorded, lane watched.
WORKING The branch gained a commit. Nothing. Let it run.
QUIET An open PR with no commit for 15 minutes.
go signal		 Analyse now. This row is the answer to what signals completion.
STALLED A branch with no PR and no commit for 15 minutes. Run the preflight. Declare a phantom rather than chase work that was never pushed.
MERGED The PR landed on main. Watch the publish run that follows.
PUBLISH The publish workflow succeeded. The page is live. Link it.
FAILED A workflow run failed, or a PR closed unmerged. Fix forward on a fresh branch. Never a force push.

Three engines

What each one is for, what tells you it finished, and what limits it.

Browser engine

Arena Agent Mode

Use it for
Judgement and craft lanes, anything wanting a frontier model.
Completion signal
PR opened as app/arena-ai-coding-agent, then quiet.
Constraint
Launched in a browser, blocked on a one-time sign-in. Prompts enter Arena's research dataset, accepted for these lanes.

Own worktree

Local opencode run

Use it for
Mechanical lanes, anything wanting tight control.
Completion signal
The process exits.
Constraint
One session per working tree, in its own git worktree under .worktrees/, never the shared clone.

Inside a session

Commander subagent

Use it for
Work that belongs to the session already running.
Completion signal
The call returns.
Constraint
Stays in that session's context, so it is for short lanes.
